# Documentation guide

The root [README](../README.md) is the quick-start for installing and running the toolkit. Use the documents below when configuring, operating, extending, or troubleshooting it.

| Document | Use it for |
| --- | --- |
| [Configuration](configuration.md) | Local files, credentials, and runtime settings |
| [CLI reference](cli-reference.md) | Commands, safety modes, and exit-status conventions |
| [Operations runbook](operations-runbook.md) | Safe day-to-day searches, applications, and recovery |
| [Data formats](data-formats.md) | Input and output artifact contracts |
| [ATS support](ats-support.md) | Provider support boundaries and diagnostic runs |
| [Security and privacy](security-and-privacy.md) | Sensitive data handling and authorization rules |
| [Architecture](architecture.md) | Components, boundaries, and extension points |
| [Troubleshooting](troubleshooting.md) | Common local setup and workflow failures |

Contributors should also read [CONTRIBUTING.md](../CONTRIBUTING.md). User-visible releases are recorded in [CHANGELOG.md](../CHANGELOG.md).

`superpowers/plans/` and `superpowers/specs/` preserve implementation history.
They may contain step-by-step snapshots from before later refactors; they are not
current user or contributor instructions.
